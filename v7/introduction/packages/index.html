Packages

Summary

This page lists the main Composer packages Dotkernel Admin depends on, covering Doctrine, Dotkernel, Laminas and Mezzio components.

Direct Dependencies

  • dotkernel/dot-cache:^4.4 - Cache component extending symfony-cache
  • dotkernel/dot-cli:^3.10 - Component for creating console applications based on laminas-cli
  • dotkernel/dot-data-fixtures:^1.5 - Provides a CLI interface for listing & executing doctrine data fixtures
  • dotkernel/dot-dependency-injection:^1.3 - Dependency injection component using class attributes
  • dotkernel/dot-errorhandler:^4.0 - Logging Error Handler for Middleware Applications
  • dotkernel/dot-flashmessenger:^3.7 - Provides session messages between redirects
  • dotkernel/dot-geoip:^3.10.1 - Synchronizes and manages GeoLite2 databases
  • dotkernel/dot-helpers:^3.9.0 - Helper utilities used across Dotkernel applications
  • dotkernel/dot-mail:^5.1 - Mail component based on laminas-mail
  • dotkernel/dot-navigation:^3.6 - Allows you to easily define and parse menus inside templates, configuration based approach
  • dotkernel/dot-rbac-guard:^3.7 - Defines authorization guards that authorize users for accessing certain parts of an application based on various criteria
  • dotkernel/dot-router:^1.1 - Dotkernel component to build complex routes, based on mezzio/mezzio-fastroute
  • dotkernel/dot-session"^5.8 - Dotkernel session component extending and customizing laminas-session
  • dotkernel/dot-twigrenderer:^3.7 - Dotkernel component providing twig extensions and customizations
  • friendsofphp/proxy-manager-lts:^1.0 - Fork of ocramius/proxy-manager
  • laminas/laminas-component-installer:^3.7 - Composer plugin for injecting modules and configuration providers into application configuration
  • laminas/laminas-config-aggregator:^1.19 - Lightweight library for collecting and merging configuration from different sources
  • mezzio/mezzio:^3.26.0 - PSR-15 Middleware Microframework
  • mezzio/mezzio-authentication-oauth2:^3.0.1 - OAuth2 (server) authentication middleware for Mezzio and PSR-15 applications
  • mezzio/mezzio-authorization-rbac:^1.10 - mezzio authorization rbac adapter for laminas/laminas-permissions-rbac
  • mezzio/mezzio-cors:^1.15.0 - CORS component for Mezzio and other PSR-15 middleware runners
  • mezzio/mezzio-fastroute:^3.14 - FastRoute integration for Mezzio
  • ramsey/uuid:^4.9 - A PHP library for generating and working with universally unique identifiers (UUIDs)
  • ramsey/uuid-doctrine:^2.1 - Use ramsey/uuid as a Doctrine field type
  • roave/psr-container-doctrine:^5.2.2 || ^6.0.0 - Doctrine Factories for PSR-11 Containers
  • symfony/var-exporter:^6.4 || ^7.4 - Exports a PHP value to a string of PHP code

Transitive Dependencies

These packages are not required directly in composer.json, but are pulled in by the packages above and used throughout Dotkernel Admin. Versions below are the ones actually resolved by Composer, not a direct version constraint.

  • doctrine/dbal:4.4.3 - Powerful PHP database abstraction layer (DBAL) with many features for database schema introspection and management.
  • doctrine/orm:3.6.3 - Object-Relational-Mapper for PHP
  • dotkernel/dot-authorization:3.8.1 - Authorization base package defining interfaces for authorization services to be used with Dotkernel applications
  • dotkernel/dot-controller:3.6.0 - Provides base classes for action based controllers similar to Laminas controller component
  • laminas/laminas-authentication:2.19.0 - API for authentication and includes concrete authentication adapters for common use case scenarios
  • laminas/laminas-form:3.24.2 - Bridge between your domain models and the View Layer
  • laminas/laminas-hydrator:4.18.0 - Serialize objects to arrays, and vice versa
  • laminas/laminas-inputfilter:2.35.0 - Normalize and validate input sets from the web, APIs, the CLI, and more, including files
  • laminas/laminas-servicemanager:3.24.0 - Factory-Driven Dependency Injection Container
  • laminas/laminas-stdlib:3.21.0 - SPL extensions, array utilities, error handlers, and more
  • mezzio/mezzio-helpers:5.20.0 - Helper/Utility classes for Mezzio

FAQ

Q: What ORM does Dotkernel Admin use?

A: doctrine/orm, together with doctrine/dbal for database schema introspection and management.

Q: Which framework underpins Dotkernel Admin?

A: mezzio/mezzio, a PSR-15 middleware microframework, along with several Mezzio and Laminas components.

Q: Which Dotkernel packages handle authorization?

A: dotkernel/dot-authorization and dotkernel/dot-rbac-guard define and enforce role-based access to the application.
